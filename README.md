# BambuScribe Write 0.1.3

这是历史版本的公开源码快照。已移除个人工程、诊断资料和开发日志，使用 GitHub 公开署名；帮助链接指向主仓库。

[下载对应版本](https://github.com/ICEIU-I/BambuScribe-Write/releases/tag/v0.1.3) · [最新版本](https://github.com/ICEIU-I/BambuScribe-Write/releases/latest) · [操作与构建说明](desktop/README.md)

迁移后的安装包由本快照重新构建，校验值与旧下载仓库的原始文件不同。代码使用原版本的依赖锁定文件；构建需 macOS Apple Silicon、Go 1.25+、Node.js 22.12+、Xcode Command Line Tools 和 Wails v2.16.0。运行 `bash desktop/scripts/release-macos.sh 0.1.3 HEAD` 生成应用与完整对应源码。
