# 正文特殊输入规范

## 基本规则

本规范适用于普通正文与正文中的独立公式。App 左下角侧栏的倾斜感叹号打开简明规则，每个类别单独一页，并配有输入示例和实际手写预览；表格、独立文本框与图片识别文字仍使用各自的规则。

- 中文、英文和标点直接输入；特殊结构可直接写在普通句子中。
- 使用英文半角 `\`、`_`、`^`、`{`、`}`。命令与参数之间不加空格。
- **花括号限定结构范围，不绘制出来；圆括号表达数学含义，正常显示。**
- 参数只有一个字符时也必须写完整花括号，不靠连续空格或换行拼公式。
- 编辑、复制和保存保留输入源码，纸面预览与导出使用排版后的笔画。

| 格式               | 输入写法                        |
| ------------------ | ------------------------------- |
| 下标／上标         | `U_{H}`、`x^{2}`、`x_{i}^{2}`   |
| 上下分式           | `\frac{分子}{分母}`             |
| 平方根／指定次数根 | `\sqrt{内容}`、`\sqrt[3]{内容}` |
| 上横线／平均值     | `\bar{内容}`                    |
| 独立公式           | `\[完整公式\]`，单独一行        |

```text
表头内阻为R_{g}，面积S=πr^{2}。
距离d=\sqrt{x^{2}+y^{2}}。
电阻满足R=\frac{U}{I}，单位为Ω。
```

## 上下标

下标使用 `基项_{内容}`，上标使用 `基项^{内容}`。基项可以是单个字符、完整的圆括号表达式或分式等特殊结构；多个字符作为一个基项时用 `{内容}` 分组。

- 上下标按所附基项名义字号的 **65% 等比缩放**，不拉伸笔形。
- 支持字库中的数字、大小写字母、中文和运算符，保留大小写。
- 同时有上下标时共用右侧一列，整体宽度取两者较宽者。
- 推荐先下标、后上标；`x_{i}^{2}` 和 `x^{2}_{i}` 显示相同。
- 同一基项最多一个下标和一个上标；重复标记如 `x_{i}_{j}` 需要合并或重新分组。
- 主字符与上下标一起换行。简单下标继续保持正文横线与普通文字基线。

```text
R_{g} U_{AK} I_{改}
x^{2} 10^{-19}
x_{i}^{2} (a+b)^{2}
{AB}_{1}
```

`R_g` 没有花括号，按普通文字显示。现成字符 `x²`、`H₂O`、`10⁻¹⁹` 仍可直接使用；复杂内容推荐标记格式。

## 分式

使用 `\frac{分子}{分母}`。第一个参数为分子，第二个参数为分母，两个参数都不能为空。

- 分子、分母水平居中，分数线按较宽一项加少量两侧留白确定长度。
- 分数线与周围等号的中轴对齐。
- 分子、分母先按“分式字号比例”排版（默认 **85%**，可调 **50%～100%**）；正文中的整个结构再按普通字高等比例缩小，保持在一行内。
- 正文分式保留上下结构，不额外占行、不单独拉扁字形；外层根号与上下标也一起适配。
- 多层分式缩小后可能较密，建议改用独立公式行；独立公式仍按实际高度排版。
- `a/b` 保持斜线写法；`½`、`⅓` 等现成字符保持原字形。

```text
电阻R=\frac{U}{I}。
平均值为\frac{U_{1}+U_{2}}{2}。
\[y=\frac{\frac{a}{b}+c}{d}\]
```

## 根号

平方根使用 `\sqrt{内容}`；指定次数时使用 `\sqrt[次数]{内容}`，例如 `\sqrt[3]{x}`。

- **横线随内容的实际宽度伸缩，钩形高度随内容的实际高度调整。**
- 内容的字距、上下标、分式与内层根号都计入尺寸。
- 被开方内容保留自身字形比例，横线位于最高笔画上方并留出间隙。
- 根号与覆盖内容作为整体换行，外层花括号不显示。
- 次数显示在根号左上方，省略次数表示平方根。
- 兼容简写 `√(内容)`、`√（内容）`、`√{内容}`，这些外层定界符不显示；推荐用 `\sqrt{内容}` 区分范围与数学括号。
- `√2` 仍是普通字符，不自动猜测横线应覆盖到哪里。

```text
距离d=\sqrt{x^{2}+y^{2}}。
几何平均值为\sqrt{a_{1}a_{2}}。
\[y=\sqrt{\frac{a+b}{c}}\]
\[z=\sqrt[3]{x}\]
```

## 上横线

使用 `\bar{内容}` 表示平均值或上横线。

- 横线覆盖花括号中的完整内容，按实际内容宽度绘制，不额外占一个字符位置。
- `\bar{U}_{H}` 只在 U 上方画横线，下标 H 放在其右侧。
- `\bar{U_{H}}` 的横线覆盖 U 和下标 H 所占的整体宽度。
- 可覆盖表达式，也可与分式、根号组合。
- 推荐用显式命令，不要求手动输入难以辨认的 Unicode 组合横线。

```text
平均电压为\bar{U}。
\bar{U}_{H} 与 \bar{U_{H}}
\[\bar{U}=\frac{U_{1}+U_{2}}{2}\]
\[y=\bar{a+b}\]
```

## 独立公式

完整公式单独一行，以 `\[` 开始、以 `\]` 结束。定界符与内容在同一源码行；外面不加解释文字或缩进。

- 正文行内直接写特殊结构；长推导和较高的多层公式使用独立公式。
- 公式按实际高度排列；长公式只在最外层等号处折行，完整计算式不拆到两页。
- 单个不可分结构超宽时，减小字号或拆分计算步骤，不强行横向压缩。
- 双击纸面的独立公式可修改内容；保存后仍保留原来的定界符。
- 旧写法整行 `\(公式\)` 继续有效。不要用 `$...$`、`$$...$$`。

```text
由欧姆定律可得：
\[R=\frac{U}{I}=\frac{12}{0.5}=24Ω\]
因此电阻为24 Ω。
```

兼容旧项目的写法：

```text
\(U_{H}=\frac{R_{H}I_{S}B}{d}\)
```

## 符号与空格

数学符号直接输入实际字符，不使用 `\alpha`、`\times`、`\cdot`、`\left`、`\right` 或 `\begin` 等命令。这是限定的数学语法，不是完整 LaTeX 或 Markdown 富文本。

```text
α β γ Δ Ω μ × ÷ ± − ≈ ≠ ≤ ≥ ∞ → ° ℃ ′ ″
```

- 中文叙述使用中文标点；数学表达式中的括号建议用英文半角括号。
- 分号 `；`／`;` 只是标点，不代表换行或参数分隔。
- 数值与单位之间建议保留一个半角空格，如 `10 mA`、`25 ℃`。
- 独立公式内的普通空格不用于对齐；正文行内结构中的空格按正文空格计宽。
- 粘贴时，特殊结构内部的连续空格会保留；结构外两段文字之间的连续空格可能整理为换行。不要用连续空格拼排版。
- 直接在正文输入的组合上横线不附着到前字；使用 `\bar{内容}`。连续下划线不会自动合并成一条填写线。

需要显示语法字符本身时使用转义：

| 想显示          | 输入       |
| --------------- | ---------- |
| 下划线 `_`      | `\_`       |
| 脱字符 `^`      | `\^`       |
| 花括号 `{`、`}` | `\{`、`\}` |
| 反斜杠 `\`      | `\\`       |

```text
显示字面命令：\\sqrt\{x\}
```

## 错误与兼容

- 参数必须非空、括号必须配对；单个结构不跨源码换行。
- 最多嵌套 **8 层**。同一层的内容过长时也需要拆分。
- 行内未完成或无效的输入保留原文，并标记问题；独立公式错误时提示原因，修正后重新排版。
- 缺字、语法错误、真实笔画碰撞或超出纸张会阻止相关页面导出。按提示补齐参数、替换符号、调整字号或拆分。
- 原有简单下标、Unicode 符号与整行 `\(...\)` 继续支持；保存不会把旧写法批量改成新写法。
- 升级后，正文中原先直接显示的 `^{...}`、`\frac`、`\sqrt`、`\bar` 等合法标记会按新规则排版；需要显示源码时使用转义。
- 客户端预览、CLI、项目重开和 G-code 导出使用同一排版规则。

| 问题写法     | 修正示例                  |
| ------------ | ------------------------- |
| `x^{}`       | `x^{2}`                   |
| `\frac{a}{}` | `\frac{a}{b}`             |
| `\sqrt{x`    | `\sqrt{x}`                |
| `x_{i}_{j}`  | `x_{ij}` 或 `{x_{i}}_{j}` |
| `\alpha`     | `α`                       |

```text
表头内阻为R_{g}，满偏电流为I_{g}。
\[R_{s}=\frac{I_{g}R_{g}}{I−I_{g}}\]
\[\bar{U}=\frac{U_{1}+U_{2}}{2}\]
距离d=\sqrt{x^{2}+y^{2}}，面积S=πr^{2}。
```
