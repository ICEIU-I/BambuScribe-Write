# 图像智能导入

工具栏 **智能导入 → 导入图像**，选择或在弹窗内粘贴 PNG/JPEG 后点击“识别并插入”，使用大模型重建。直接向纸面粘贴图片则使用原有 OCR 和线稿提取，不打开智能导入弹窗、不调用大模型。选中已有图片再打开“导入图像”，点击“重新识别”会替换该图片的图形，保留位置、尺寸、手工文字和擦除记录；一次撤销恢复原图。

识别时点击右上角 × 或按 Esc 只收起窗口，任务继续在后台运行，完成后自动插入；可以继续编辑正文。底部显示识别状态和已用时间，点击“查看”或再次打开“导入图像”可回到同一任务，不会重复请求。失败会显示原因并保留原图供重试。“取消识别”才会取消当前任务；切换项目或退出应用也会停止旧任务，避免把结果插入其他项目。

模型连接复用表格导入保存的 API 地址、协议、模型和 Key。图片会发送到这里配置的服务；Key 不进入项目文件。支持 Responses 和 Chat Completions，当前实测模型为 `gpt-6.1-sol`。

支持一次多选或拖入多张图片，也可连续粘贴追加；每批最多 10 张、单张最多 8 MB、总计 48 MB。最多同时识别 3 张，其余排队，窗口和底部状态显示完成数量。全部成功后按添加顺序一起插入，图间留 4 mm，放不下时换页，一次撤销恢复整批。失败图片显示原因，可更换、移除或点击“重试失败图片”，成功结果保留；修改补充要求会重新识别整批。取消会停止所有请求和排队，切换项目也不会插入旧批次的结果。

插入从打开导入时的光标位置开始，后续图片接在前一张下方；完整图片区域由正文整行避让，下方文字自动顺延，必要时文字换页。图片可使用纸张底部的留白，只有图片本身超出整张纸才换页，不会因下面已有正文而跳到正文后面。撤销或删除图片后，正文自动回到原来的位置。

每张图只发出 **一次请求**：原图、左右两个有重叠的局部放大图与固定提示词一起发送，返回线段/折线、圆、文字及其坐标。GPT-6 系列使用 high 推理强度。没有第二轮模型复核，没有人工复核步骤，也不自动重试。坐标范围、数量、字库与简单上下标支持在本地校验，成功后直接渲染并插入。格式错误、越界或不支持的文字会显示原因，文档不变。

文字使用内置手写字库；模型按完整原图的实际字高，在 1.5–2 倍内为每个文字块选择大小和位置，尽量利用图片横向空间，并避开其他文字、图线和符号。图注不插入填充空格，字距和额外字距沿用正文设置；识别请求会提供当前字体的间距参数，供模型预留文字宽度。客户端按实际变形后的笔画拟合模型给定的最终文字框，保持字形比例和以毫米计的额外字距，不叠加放大。图形比例及连线关系保持原样。已有图片的字距随正文设置更新；重新安排字号与位置需对该图重新识别。

线段不再沿像素描摹；圆按模型圆心和半径绘制。支持拖动、等比缩放、橡皮擦、叠加文本框、复制、撤销及 G-code 导出。模型结果保存于图片的 `diagram` 字段，CCF 格式版本升为 4；旧项目仍可打开，新项目需要本版本或更高版本。移动、缩放、保存重开和导出不再调用模型。

纸面粘贴已恢复原有自动 OCR：未配置本机模型时使用 macOS Vision，启用了 `image-ocr.json` 时使用本机 PaddleOCR/Pix2Text，识别规则、缓存、人工文本框和擦除记录沿用原实现。紧凑分式截图可由本机公式模型完整识别并按结构重绘，根式等不支持的结构保留原笔画；该流程不需要表格模型的 API Key。已经通过图像 Agent 重建并保存 `diagram` 的图片继续直接渲染矢量，不再进入 OCR，也不会自动重新调用模型。
