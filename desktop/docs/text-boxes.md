# 文本框

点击顶部「文本框」，再单击纸面任意位置，即可直接输入手写文字。文本框可以放在空白纸面、表格上方或图片上方，适合表名、图注、单位和补充说明；它独立于图片，不会擦除下方笔画。

文本框按当前宽高、内边距、上下标和换行自动使用能容纳完整文字的最大字号（1–40 mm）。放大框时文字放大，缩小框时文字缩小；旧项目中的文本框同样生效。上方显示只读的自动字号。

文本框的字距百分比与额外字距跟随正文的排版设置，汉字、标点、英文及空格使用相同的间距规则。额外字距以毫米保持固定，缩放文本框时不会随字号放大；调整字距后会重新计算可用字号。

- Enter 保存，Shift+Enter 换行；没有换行符时保持同一行。编辑后自动适配字号；缩至 1 mm 仍放不下时提示加宽文本框或手动换行。
- 单击选中，拖动框内空白或上方的点阵手柄移动，可跨页；右下角拖动调整大小，文字即时同步缩放。上方可调整左／中／右对齐。
- 双击重新编辑。选中后 Delete／Backspace 或右上角 × 删除整个文本框；输入时删除键仅删除文字，Esc 取消这次编辑。
- 选中文本框后复制／剪切／粘贴会保留文字、尺寸和字号。在纸面点击目标位置再粘贴，可以放到其他页面；编辑文字时使用普通文本剪贴板。
- 插入、编辑、移动、缩放和删除都可以撤销／重做；草稿和 `.ccf` 项目保留文本框。保存时会先提交正在输入的文字。

手写预览和 G-code 导出／上传使用相同笔画。选框、手柄和编辑控件不会输出；缺字、文字宽度不足或超出纸张时会阻止导出，并提示如何处理。

下标使用 `_{内容}`，例如表名 `表1 I-U_{AK}关系`；编辑时保留该写法，预览和导出显示真正的大写 AK 下标。

旧项目中的图片内文本框仍可编辑和调整，新插入的文本框均按纸张位置独立放置。擦除工具可用于整张纸面的正文、图片、表格和文本框，详见[擦除说明](eraser.md)。
