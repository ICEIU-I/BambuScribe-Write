# 表格工具

在书写工具栏点击「表格」，选择普通网格表、三线表或仅横线表，设置行数、列数和宽度后插入。第一版支持每表 1–50 行、1–20 列，文档最多 50 张表格。所有位置、宽高、字号和内边距均以毫米计算。

表格按每个单元格独立计算最大可用字号（1–40 mm），使用实际笔画边界、合并区域、上下标、换行及内边距。短数字不会被长表头一起缩小，文字等比缩放并按实际笔画居中。放大、缩小、改字或调整行列后自动重算，已有小字号表格重新打开也会生效；表格设置显示只读的自动字号范围，独立文本框同样按框的尺寸自动适配。

- 单击选中单元格，拖动或按住 Shift 单击可选择一片区域。双击输入手写文字，Enter 保存，Shift+Enter 换行，Tab／Shift+Tab 保存并切换单元格；中文输入法选字时 Enter 不提前保存。
- 选中多个单元格后点击「合并」；合并时按行顺序保留各格文字，用换行分隔。「拆分」保留原格文字在左上格，其余格为空。
- 点击表格上方的「设置」或右键，可以调整样式、行列尺寸、内边距、对齐和边框，也可以插入／删除行列。只有 Shift+Enter 插入的换行或粘贴内容中的换行才会增加文字行数；长文字保持在同一行，并参与所在单元格的字号适配。行尾空格不参与排版，原文字仍完整保留。
- 手动换行后，按单元格现有高度调整字号，合并单元格使用合并区域总高度。缩短文字后字号重新放大；空白测量格不会限制其他文字的字号。达到最小 1 mm 后，高度仍不足时保留原有撑高保护，宽度不足仍阻止导出。
- 拖动表格上方的点阵手柄可移动整张表格并跨页；拖动右下角调整尺寸，拖动列顶／行左的小方块调整列宽／行高。文字同步放大或缩小，拖动时即时预览，松手后与原生排版一致。
- 从 Excel 等软件复制单元格区域，粘贴到空白纸面会创建表格；粘贴到选中的单元格会从该格填入并按需扩展行列。带引号的多行单元格、制表符和空白列会保留，正文粘贴整理规则不作用于表格内容。
- 选择单元格时复制／剪切的是该区域的文字；单击移动手柄取消单元格选区后，复制／剪切的是整张表格，包含合并、样式和尺寸。系统剪贴板同时保存标准 HTML 表格作为原生 WebView 的兼容回退。
- 单元格选区中的 Delete／Backspace 清空文字；未选择单元格时删除整张表格。表格的插入、修改、拖动、粘贴和删除均进入正文与图片共用的撤销／重做记录。

图片、表格和独立文本框允许互相重叠，保留指定位置。正文按整行避让对象，整行移到下方或下一页，不拆到对象两侧或图间空隙。对象自身超出纸张时整块移到下一页，不拆分表格、不缩小字号。表格使用文字撑开后的实际高度，图片对象按旋转后的框检查纸张边界，正文避让实际笔画的外接范围。删除或缩小对象会释放正文占位；撤销、重做、保存后重开与导出使用同一规则。

自动换页的位置用于显示和导出，项目保留原始摆放位置；拖动对象可重新指定位置。删除正文不会删除独立对象。超过整页的对象需要缩小或拆分；列宽不足或缺字仍会阻止导出／上传。

表格格线和手写文字直接组成矢量笔画，共享格线只绘制一次。纸面横线辅助显示在表格区域内隐藏，预览笔画与单页 G-code／全部页 ZIP／上传使用同一份排版结果。

下标使用 `_{内容}`，例如 `U_{AK}/V`。花括号中的原字形会等比缩小并下移，保留大写字母；编辑时保留这段写法，预览与导出显示下标。不完整、空白或嵌套的花括号组按原文字显示。

字母后紧跟的组合上横线（U+0305 或 U+0304）绘制在该字母上方，例如 `U̅_{H}/mV`，不占额外字宽；表格和独立文本框共用此规则。连续两个及以上下划线（如 `________`）绘制为一条完整的填写横线，原文字和占位宽度保留。

草稿自动保存表格结构。含表格的项目保存为 `.ccf` 格式版本 2，仍可打开原有版本 1 的项目；旧版本客户端会拒绝版本 2 文件，避免在读取时静默丢失表格。

智能导入统一规范单元格、表名和说明中的空格：`1 000` → `1000`、`I_{S} = 10.00 mA` → `I_{S}=10.00 mA`、`置于 C 型电磁铁` → `置于C型电磁铁`。中文及中文标点旁不插空格，英文词间和数字与单位之间保留一个空格；小数点、正负号、上下标、填写横线、换行和制表符保留。规则同时用于模型提示词与识别结果处理，在识别预览中即可看到整理后的文字；已保存的项目和导入完成后的手动编辑不自动整理。
