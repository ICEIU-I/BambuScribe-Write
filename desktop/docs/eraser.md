# 纸面擦除

点击顶部「擦除」后，可直接在纸面任意位置操作，无需图片或对象选中；正文、图片线稿、表格边框和文字、独立文本框都可擦除。

- 「框选」：拖出矩形，擦除框内笔画。
- 「自由」：点击或沿任意轨迹拖动，仅擦除圆形笔刷经过的位置。粗细为实际纸面直径：1.6、3.6、6.4 或 10 mm，缩放预览不改变实际粗细。
- 每次拖动或点击是一项撤销记录，支持 ⌘Z 撤销、⇧⌘Z 重做，Esc 取消当前拖动并返回选择。

擦除实时预览，并在 G-code 导出和上传中裁剪同样的笔画；纸张横线不受影响。正文原文、图片原始数据和表格结构仍可编辑。

纸面擦除记录本次实际擦到的图片、表格和文本框；后来新增、复制或从其他位置移入的对象不会被旧擦除遮挡。需要擦除新对象时，再执行一次擦除即可。范围仍按原页原位置保存；被擦过的对象移出该范围会恢复原来的笔画。正文重新排版时仍按纸面范围擦除，旧项目中的图片内部擦除仍随图片移动。

草稿和 `.ccf` 项目保存擦除范围及对象列表，预览与导出共用。旧版未记录对象列表的纸面擦除会保留原效果，并在编辑对象前按当前内容固定作用对象；建议用本版客户端和 CLI 继续编辑、导出。复制整页会将擦除关联到复制后的对象，支持撤销和重做。
