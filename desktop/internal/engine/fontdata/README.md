# 内置笔画字库

“教案专用”和“DC体”由项目维护者 [ICEIU-I](https://github.com/ICEIU-I) 原创制作，作者已确认可随本项目公开分发。两套笔画数据及本项目补充字形按 [GPL-3.0](../../../../LICENSE) 分发，Copyright (C) 2026 ICEIU-I。

- `handwriting.json.gz`：原“教案专用”字库。
- `dc.json.gz`：由作者原始文件 `15_DC体.json` 打包，6,878 个原始字形，完整覆盖“教案专用”的 6,848 个原始字形。原文件 SHA-256：`8a426dc7d4e2ac864a55f3dddbf990b5273b424febb65e10eb6b9dfcdbf86904`。

DC体另补充 285 个符号，共 7,163 个可书写字形，与现有教案专用运行时字库的字符集合一致。

DC体的“懈”“幛”“悻”原始纵坐标分别达到 11.333、11.022、11.133，超过排版器的 11 单位字框。仅这三个字整体等比缩小到框内，不裁笔画、不分别拉伸横纵轴，其余字形保持原数据。

加载时按每个字体单独补充物理/数学符号、希腊字母、单位、箭头、上下标及序号。已有原始字形优先；缺少的上下标数字、分数数字及圈号使用当前字体自己的数字和括号组合，避免混用另一套数字。覆盖回归包含原字库的全部运行时字形和实验文本样例；组合上横线由表格/公式排版器附着绘制。

字体选择保存在 `layout.fontId`（`handwriting` 或 `dc`），随草稿和 CCF 保存。旧项目未设置该字段时仍使用教案专用；正文、表格、文本框、图像标签、预览与 G-code 共用所选字体的笔画及尺寸。

切换后保留现有排版参数并按新字形重新分页。行间重叠按每个字在纸上的横纵墨迹范围检查；当前霍尔教案可沿用 85% 行距与 76.5% 字距。字形比例、字号和行距保持原值，缺字、真实区域重叠及纸张边界检查继续生效。表格按单元格宽高自动匹配最大可用字号。

在 `desktop` 目录重新打包或导出包含补充字形的完整 JSON：

```sh
python3 tools/fonts/pack.py /path/to/15_DC体.json internal/engine/fontdata/dc.json.gz
go run ./tools/fonts --font dc --output /path/to/15_DC体_补全.json
```
