macOS Apple Silicon 首个桌面测试版。

- 纸面编辑、双手写字库、自动分页、独立文本框和可编辑表格。
- 图片粘贴、系统 OCR、线稿提取、一次性笔画擦除，以及可配置的智能导入。
- `.ccf` 项目自动保存、页面复制/插入/删除/排序、逐页 G-code 导出与 A1 局域网上传。

下载 `BambuScribe-Write-0.1.0-macos-arm64.dmg`，打开后将应用拖入 Applications。也可使用 ZIP 安装。适用于 M 系列 Mac、macOS 13 及以上；Intel Mac、Windows 和 Linux 尚未提供安装包，旧版 macOS 未进行实机验证。

**此版采用临时签名，尚未经过 Apple 签名公证。** 若下载后提示无法验证开发者，尝试打开一次，再到“系统设置 → 隐私与安全性”选择“仍要打开”。无需关闭系统安全保护。

字库和系统 OCR 已包含，无需安装开发工具。可选 Python OCR 模型不包含在包内，智能导入需自行配置模型服务。上传前请在 A1 完成归零、笔尖定位和高度校准，并以短句试写。

附件含对应源码、`SHA256SUMS` 和构建信息。基于 [Animesh-Varma/BambuScribe](https://github.com/Animesh-Varma/BambuScribe)，按 GPL-3.0 分发。

历史版本迁移：本包从清理过个人信息的对应源码重新构建，修正帮助链接；校验值与旧版文件不同。
