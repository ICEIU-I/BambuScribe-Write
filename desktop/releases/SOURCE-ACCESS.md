# 对应源码

BambuScribe Write 按 GPL-3.0 分发。公开源码、构建步骤和问题反馈统一位于 [ICEIU-I/BambuScribe-Write](https://github.com/ICEIU-I/BambuScribe-Write)。

每个发布页提供 `BambuScribe-Write-版本-source.zip`，包含对应代码、内置字库、依赖锁定文件与构建脚本。每版 `build-info.json` 中 `sourceCommit` 对应公开源码提交。历史版本为清理个人信息后重新构建的包，与旧发布文件的校验值不同。

旧下载仓库保留至 1.0.0 的安装包和更新过渡入口。后续版本请使用主仓库；0.1.0 需手动安装，0.1.1 及以上旧版可通过应用内更新迁移。
