# A1 手写助手

Go + Wails + Vue 桌面应用，第一版面向 macOS Apple Silicon。继承上级项目的 GPL-3.0 许可证。

## 使用

打开 `build/bin/BambuScribe Write.app` 即可编辑。字库随应用打包，离线支持排版、自动分页和手写预览；左侧栏底部可切换浅色与深色主题。

“排版设置 → 字体”可选择“教案专用”或“DC体”。DC体覆盖原字库全部用字，并补齐教案常用的公式符号；上下标和序号使用 DC体自身数字组合。选择随草稿及项目保存，旧项目沿用教案专用。切换字体后按新字体重新排版，上传前请检查分页和对象尺寸；详见[字库说明](internal/engine/fontdata/README.md)。

“排版设置 → 文字 → 手写变化”可让每个字符产生轻微的大小、倾斜与笔形差异，并在可用空白内微调字距和行距，开启时默认为 20%，可调整强度或点击“换一组”。正文、上下分式、表格、文本框和图片中的手写文字均使用同一规则；分数线保持平直并跟随公式，表格边框和图形保持原样。变化结果随草稿和项目保存，重开、预览和导出一致；关闭后恢复原字形。旧项目默认关闭。

正文支持 `R_{g}` 下标、`x^{2}` 上标、`x_{i}^{2}` 共列上下标，以及 `\frac{a}{b}` 分式、`\sqrt{内容}` 自适应根号、`\sqrt[3]{x}` 指定次数根和 `\bar{U}` 上横线。简单下标保持正文横线与字形基线，行内分式连同相接的公式按实际行高等比例适配，充分利用一行高度并保留上下间隙，不额外占行；结构整体换行，预览和导出共用笔画。独立公式推荐单独一行 `\[公式\]`，兼容原有整行 `\(公式\)`；双击可编辑。未完成的行内结构保留源码并提示，语法错误或缺字阻止导出。左下角侧栏倾斜感叹号打开按类别分页的输入规则，展示实际手写预览并支持复制示例；完整说明见[正文特殊输入规范](docs/writing-syntax.md)，弹窗示例取自这份文档。

左侧图标栏放置新建空项目、打开、另存为、书写台／设备台、页码和主题切换；悬停或键盘聚焦显示名称与说明。页码支持方向键、Home 和 End 导航，图标栏可收起。顶部工具栏提供编辑工具与缩放，“排版设置”在右侧打开，可一边修改参数一边编辑纸面。窄窗口下设置面板覆盖纸面右侧，关闭后恢复完整视图。

拖动侧栏页码可调整整页顺序，落点线显示插入位置；拖到列表边缘会自动滚动，Esc 或拖出侧栏可取消。右键页码可选择“复制整页”“插入空白页”或“删除整页”。复制会在原页后插入独立副本，保留正文、图片、表格、文本框和擦除效果；插入空白页会在所选页后新增一张可编辑空白纸，后续页面顺延。这些操作均可撤销。分页、逐页网格和笔画擦除随 CCF v6 保存，旧项目仍可打开。

点击“新建空项目”、选择“文件 → 新建空项目”或按 `⌘/Ctrl+N`，创建一张空白页；正文、图片、表格、文本框及擦除记录清空，沿用当前排版、书写参数和主题。当前内容未保存为项目文件时可选择先保存、不保存或取消；取消保存或保存失败会保留当前项目。新项目不沿用原文件路径，撤销不会恢复上一个项目的内容。

“文件 → 另存为…”和“打开项目…”默认定位到 `~/Documents/BambuScribe/projects`，目录不存在时自动创建，可在文件对话框中选择其他位置。默认文件名取正文第一行，去掉首尾空白并补上 `.ccf`；第一行为空时使用“手写项目.ccf”，文件名仍可修改。`.ccf` 项目集中放在 `projects` 中，该目录不参与 Git 提交。

尚未保存的新项目自动保存为草稿，状态栏显示“草稿已保存”。成功保存或打开 `.ccf` 后，后续编辑自动写回该文件，不再保留另一份草稿；多次另存为以最近一次保存成功的位置为准，取消或失败不会改变目标。重启后直接恢复该文件，关闭窗口前完成待保存内容；文件不可写时显示原因并保留窗口。`⌘/Ctrl+S` 保存到当前文件，未命名时选择位置；`⌘/Ctrl+Shift+S` 另存为。窗口与页面使用同一标题，灰点只在项目文件尚有待保存改动时显示。

macOS 绿色窗口按钮及“窗口 → 全屏”（`⌃⌘F`）支持进入和退出全屏；`Esc` 优先用于收起弹窗、退出编辑及取消拖动。

正文中按 `Enter` 换行，按 `Tab` 插入四格空白并保持纸面焦点；缩进随项目保存，可撤销和重做。`Shift+Tab` 仍用于切换焦点。

1. 在书写页输入文字，调整字体大小、字距、行距和页面设置，翻页检查结果。字体大小采用百分比单位，默认 110%（基准行高 15 mm 时为 16.5 mm 字框）；调整纸张或基准行数时保持字号比例。字距、行距可独立调整为基准间距的 50–200%，调整间距不改变笔画尺寸；85% 表示收紧 15%。额外字距和段距以毫米追加。已有草稿和项目保留原毫米尺寸及间距，缺少间距参数时按 100% 恢复，不自动改字号。
2. 页面默认模板为“新建笔记”，纸张 163 × 240 mm，四边 0 mm，固定 16 行；可切换 A4、B5、自定义尺寸，以及固定／随机行数。
3. 在设备台用 `+` 新增 A1 实例，列表显示实例名称和连接状态，点击实例打开弹窗编辑名称、IP 和明文访问码，`−` 删除实例；新增后直接打开编辑弹窗。每次连接时自动检测序列号。打印机需开启 LAN 模式及固件支持的开发者模式。
4. 设备页只配置书写参数：X/Y 偏移、抬笔 Z、落笔 Z、None／自动 XY 原点和提示音。首次书写前在打印机上手动归零、定位笔尖并校准落笔高度。
5. 自动 XY 原点默认开启，抬笔位置 7.0 mm、落笔位置 3.4 mm；实际安装笔后请根据机器状态修改这三个参数。
6. 点击“上传”打开弹窗。文件名前缀默认取首行编号（如“实验三十一”取 `31`），可自行修改；页码后缀自动生成。点击“上传全部”一次上传所有有内容的页面，或选择页码后点击“上传特定页”（默认当前页）。空白页跳过，保留原页码；页面文件为 `31-page1.gcode` 等。上传过程中弹窗及底部任务栏显示进度，并可取消；失败或断线会中止剩余上传。上传成功后在 A1 屏幕选择页面文件开始书写，换纸、启动、暂停与停止均在 A1 端操作；客户端只负责上传。
7. 顶部「选择」用于移动和缩放对象，图片可直接拖到其他页，拖到预览窗口上下边缘会自动滚动；「文本框」可在纸面任意位置插入独立手写文字，新建后直接输入，Enter 保存、Shift+Enter 换行。文本框支持跨页移动、缩放、字号、对齐和复制粘贴，详见[文本框说明](docs/text-boxes.md)。「擦除」可在纸面任意位置移除正文、图片、表格和文本框笔画，“框选”方式移除矩形内部，“自由”方式只擦除笔刷经过的位置；无需先选中图片。擦除支持撤销、保存和导出，详见[擦除说明](docs/eraser.md)。`⌘1 / ⌘2 / ⌘3` 切换工具，`Esc` 回到选择或取消正在进行的拖动。OCR 识别框仅用于显示和导出，不提供微调操作。

上传和单页导出使用 UTF-8 `.gcode`，与本机炽写 3.0.224 的 A1 上传格式一致；文件没有 3MF 耗材声明，也没有加热、装载耗材或挤出指令。导出全部为包含各页 `.gcode` 的 ZIP。旧版 `.gcode.3mf` 仍会保留在存储卡上，请重新上传并在 A1 选择新的 `.gcode` 文件，客户端升级不会修改旧文件。

同页正文、图片、表格和独立文本框按实际笔画顶部从上到下书写，顶部相同则从左到右。正文按整行、每个对象按整块完成，保留字内和图内笔画顺序。移动或旋转对象、擦除后重新排版即更新顺序；已上传的文件需重新上传。

原点模式对齐本机炽写的“书写框起点”配置：“自动 XY 原点”将启动时的笔尖位置设为书写区域左上角（页边距内侧，只重设 XY，不重设 Z），需先在 A1 上定位笔尖；“None”沿用 A1 当前 XY 坐标，不自动居中。X 正偏移向右，Y 正偏移向下；纸面排版、页边距和对象间距保持原样。每页结束先升到绝对 Z=50 mm（若配置的抬笔位置更高则沿用更高值），等待抬升完成后再移动 X/Y，避免回程划过成品；自动模式回到启动位置，None 模式回到当前坐标系的 X0/Y0。启用提示音时播放完成提示，等待运动和提示音结束后完成该页任务，保持三轴电机使能和回程高度，方便换纸。

连续换页请选择“自动 XY 原点”：首次归零并用打印机按钮定位起点后，每页写完自动抬笔回到同一位置，换好纸后在 A1 屏幕选择下一页开始，无需每页重新归零或重复调整 X/Y。换纸时保持喷头、热床和龙门位置；断电、释放电机、手推轴、重新归零或位置丢失后，需重新定位。文件不主动释放电机，固件是否在任务结束或长时间空闲后自动释放仍需实机确认。旧文件需要重新导出或上传才会使用此行为。

行程检查包含全部笔画、启动原点及结束停靠，以实际移动范围判断，A4 纸张高度本身不阻止上传。已有偏移、抬落笔位置及模式值保持不变。

普通书写、空移和抬落笔使用 `G1 F16000`（16000 mm/min，XY 目标约 267 mm/s）；表格边框落笔绘制单独使用 `F11200`（11200 mm/min，约 187 mm/s），降低 30%。表格内的文字沿用普通书写速度，边框擦除后保留的线段仍使用较低速度。每页开始将速度倍率恢复为 100%、加速度倍率恢复为 1，设置 XY 加速度上限及移动加速度为 12000 mm/s²、Z 加速度上限 1500 mm/s²、XY 速度上限 500 mm/s、Z 速度上限 30 mm/s。XY 加速度采用[拓竹官方 A1 配置](https://github.com/bambulab/BambuStudio/blob/master/resources/profiles/BBL/machine/Bambu%20Lab%20A1%200.4%20nozzle.json)的机型上限，避免短笔画继续受此前 6000 mm/s² 初始化限制。Z 抬落笔在 F8000 时已经超过设定的轴速度上限，继续加 F 不会提高该上限；增大抬落高度差会增加每笔往返时间。短笔画仍受加减速、转角和固件执行影响，总耗时不保证减半。抬落笔高度使用原校准值，不修改电机电流、床面补偿或软限位，不写入永久设置。升级后需重新上传文件；实际速度和纸面接触效果需按安装条件验证。

所有页面的书写笔画统一使用配置的落笔 Z 和抬笔 Z，不按行号或纸面位置改变高度；仅整页结束后的回程和换纸使用上述较高 Z。旧项目中的底部降笔参数不再生效；更新后需重新上传页面文件。

页面尺寸和机器行程分别处理，超界路径会阻止输出。缺字标成红框；常用标点已补充，其余缺字须修改后再导出。

字号可以超过基准行高，排版按实际笔画判断是否能放入正文；行间重叠按真实笔画距离及预览笔宽检测，字形外框相交不单独触发。间距过小导致笔画相碰时，发生冲突的文字下方显示红色波浪线；请增大行距或减小字号，修正后标记自动消失。波浪线仅用于编辑提示，不进入导出或上传的笔画。基准行数用于确定字号和原始行高，调整行距后会重新分页，横线和上传坐标同步更新，独立对象保留指定位置作为摆放起点。正文按整行避让图片、表格和独立文本框；对象进入正文行时，整行移到下方或下一页，不将正文拆到对象两侧或图间空隙。图片的实际笔画未占到正文行时保留原有位置；图片、文本框和表格允许互相重叠并保留指定位置，仅对象自身超出纸张时整块换页，预览与导出使用同一实际位置。

图片中的公式和识别不确定的文字保留原有笔画与位置，可信的普通标签才自动转为手写，避免改变上下标、单位和符号。旧草稿中未人工调整的自动 OCR 区域会重新生成，人工擦除和文本框保留。可选的[本机 OCR 试验](docs/local-image-ocr.md)使用 PaddleOCR 与裁剪后的 Pix2Text 交叉识别，并支持简单上下标；存在分歧时继续保留原图。

自动模式的上传弹窗按全部页的实际笔画、偏移和停靠点显示 A1 物理起点 XY 范围。重设原点不会增加实际行程：例如向下书写 244.7 mm，起点 Y=240 mm 会让底部约 4.7 mm 被截断，需把起点设到允许范围内（如 Y=250 mm），并调整纸张使笔尖对准书写区域左上角。换页启动前确认纸张对齐且机器位置未变，旧上传文件不会随客户端更新而改变。

未连接设备时，填写有效校准参数后可以导出。导出文件需要从已经归零、位置有效的 A1 启动，不包含自动归零；请先以小范围短句试写。

客户端打开后会并行连接全部已保存 IP 和访问码的实例，正文编辑与排版照常可用；无连接信息时跳过，连接失败显示原因并可在设备台手动重试。各实例独立连接、查询状态、上传及取消，设备台和上传弹窗可选择上传目标。重命名保持连接，编辑 IP／访问码会断开对应实例，删除关闭该实例；其他实例继续工作。书写参数由当前文档共用，使用不同打印机前分别确认校准。

自动连接与手动连接都会重新检测序列号；检测失败时检查 IP、网络、打印机电源及 LAN 模式后重试。每个实例在启动时尝试一次，手动断开后保持断开；只建立局域网连接并查询状态，不自动上传或开始书写。实例及访问码只保存本机，不进入 `.ccf` 项目。

## 构建

开发环境需要 Go 1.25+、Node.js 22.12+ 和 Xcode Command Line Tools。最终 `.app` 不要求用户安装这些工具。

```sh
go install github.com/wailsapp/wails/v2/cmd/wails@v2.16.0
cd desktop
wails build -platform darwin/arm64 -trimpath
```

本地开发：`wails dev`。Wails 的浏览器调试服务仅用于开发，发布版是独立桌面窗口。

```sh
cd desktop/frontend
npm ci
npm run build
cd ..
go test -race ./internal/...
go vet ./...
```

## 模块

- `internal/engine`：字库、排版、笔画坐标、G-code 与逐页导出。
- `internal/printer`：发现、MQTT 状态回报、FTPS 批量上传与取消。
- `internal/storage`：草稿、主题、校准及连接配置的原子保存。
- `internal/application`：Wails 方法绑定、文档版本缓存及原生文件保存。
- `frontend/src/components`：编辑、预览和设备组件；`state` 管理界面状态，`services` 管理桌面调用。

## CLI

编辑、表格、文本框、图片、擦除、预览、导出和设备通信均可通过独立命令行调用，见[CLI 使用说明](docs/cli.md)。

```sh
go build -trimpath -o build/bin/bambuscribe ./cmd/bambuscribe
./build/bin/bambuscribe tools
```

## 图片擦除验证

在“选择”模式下，从纸面空白处拖动可框选图片、表格和独立文本框；与框相交的对象会整块选中。框选后拖动选区或任意选中对象可整体移动，保持相对位置；可跨页，靠近窗口边缘自动滚动，整组限制在纸张范围内，一次撤销恢复全部对象，拖动中按 `Esc` 取消。按 `⌘C / Ctrl+C` 复制，点击目标位置后按 `⌘V / Ctrl+V` 粘贴，保留内容、尺寸、原横坐标和相对位置；点击决定目标页和纵向位置，可与已有对象重叠，页内放不下才换页，整组粘贴可一次撤销。目标纸张较窄时，仅将整组平移到纸内。`Esc` 取消框选。正文不参与对象框选，在文字上拖动仍选择正文，空白处单击仍放置正文光标。

选中整张图片后可用 `⌘C / Ctrl+C` 复制、`⌘X / Ctrl+X` 剪切，再点击目标页的位置并用 `⌘V / Ctrl+V` 粘贴；也可先用页码按钮切换目标页。副本保留原图、尺寸、旋转、擦除和手动文本框，没有指定位置时稍微错开。跨页拖动、剪切和粘贴均可撤销/重做；文本框内编辑文字时使用正常的文字剪贴板。

手动文本框会覆盖框内的底图和较早添加的文字，导出也只书写可见部分。单击选中、拖动移动、右下角缩放，双击修改文字；右上角 `×` 或 Delete/Backspace 删除，移动或删除后原位置的底图会恢复。

选中文本框按 `⌘C / Ctrl+C`，点击图片中的目标位置后按 `⌘V / Ctrl+V`，可重复粘贴；不指定位置时副本会稍微错开放置。复制保留文字和大小，粘贴、移动、缩放和删除都支持撤销/重做。OCR 识别框不显示编辑控件。

擦除的“自由”方式只移除圆形笔刷经过的位置，“框选”方式移除矩形内部；两者是同一个擦除工具的两种方式。历史擦除区域不显示选框，撤销/重做按整次操作恢复。图片尺寸变化时笔刷随图片等比例变化，工具栏用细、中、粗、特粗表示，圆点显示实际范围。

cd desktop/frontend

配置保存于 macOS 的应用支持目录 `BambuScribeWrite/settings.json`，权限为 `0600`。访问码在实例编辑弹窗中以明文显示。损坏的配置文件不会自动覆盖。

## 智能导入表格

工具栏“智能导入”支持一次选择或拖入多张 PNG/JPEG，也可连续粘贴追加（每批最多 10 张、总计 48 MB，单张最多 12 MB）。最多同时识别 3 张图片，每张只调用一次模型，完成后直接进入预览；结果按图片添加顺序排列。失败图片可单独重试，已完成结果保留，取消会停止本批所有请求与后续排队。

识别完成进入统一预览：对照原图修改文字，拖动表格连同表名、说明的位置，用页码和毫米宽度控件跨页或并排摆放，确认后一次性插入。默认宽度保持不变，行高按实际文字、上下标及显式换行取最小值，保留内边距和最低 3 mm 行高。宽度不足会自动缩小对应字号（最低 1 mm）；手动摆放允许对象重叠，越界会阻止插入。插入后默认单独拖动表格、表名或说明来调整相对位置；选中对象后拖动“整组移动”按钮，可按调整后的相对位置一起移动。两种移动均实时预览、支持跨页，限制在整张纸内，可使用底部页边距；允许与其他对象重叠，正文自动整行避让。表格文字按每个单元格的实际笔画边界独立取最大可用字号（1–40 mm），长表头不再缩小其他数据格，放大、缩小、改字及调整行列均自动适配，已有表格同样生效；达到 1 mm 后限制最小单元格尺寸。同组关系随项目保存，整批插入和每次移动均可撤销。自动排列会避开已有内容，空间不足顺延下一页。

项目内提供 `$bambuscribe-table-import` Codex skill，使用同一识别格式和排版器。CLI 新增 `recognize-table`、`import-table`、`live snapshot/import`，见[调用说明](docs/cli.md#图片识别与自动导入)。模型连接与 Key 仅保存本机，不包含在 .ccf 中。

## 图像智能导入

直接向纸面粘贴图片使用原有 OCR 和线稿提取，不调用大模型，适合快速插入公式等小图。需要大模型重建时使用工具栏“智能导入 → 导入图像”，支持多选、拖入和连续粘贴追加，每批最多 10 张、单张最多 8 MB、总计 48 MB，最多同时识别 3 张；每张调用一次，成功后按添加顺序一起插入，图间留空、放不下时换页，一次撤销整批。文字由模型按原图字号的 1.5–2 倍自动放大并安排位置。失败只重试未完成图片，成功结果保留；选中旧图可重新识别。详见[图像导入说明与实测结果](docs/diagram-agent.md)。

擦除只删除操作当时碰到的笔画片段；移动、缩放或旋转后，删除结果跟随原笔画，旧纸面区域不再继续擦除。修改文字会生成完整的新笔画，新增或移入的文本框、表格、图片不受历史擦除影响。框选和自由擦除均支持撤销、重做及保存重开，预览与导出使用相同的删除结果。

## 数据处理导入

工具栏“智能导入 → 数据处理”分别添加原始数据和参考样例，支持 PNG/JPEG 多图选择、拖入或粘贴；每组最多 10 张、单张最多 12 MB、两组合计 48 MB。整批图片一起识别，跨图延续的同一计算内容合并，生成时按正文空间自动换行、分页，不沿用图片的分页和留白。沿用现有模型连接，可补充本次仪器常数等要求；只生成参考包含的计算项目、顺序及精度。

预览中核对并修改读数、参数、计算式和精度，程序重新计算结果；缺失或不确定读数需先核对。支持四则运算、整数幂、绝对值、平方根与小数舍入，单位换算由明确系数计算。插入后是正文和公式笔画，分式上下排列，分数线按内容宽度绘制；分子、分母默认采用正文的 85% 字号，可在预览和排版设置中调为 50–100%。公式按实际高度紧凑排布，长计算式在等号处换行，完整公式不会拆到两页。

双击生成的公式可修改原数据并重算整块内容，支持撤销/重做及保存重开。删除部分公式后，剩余公式可双击直接编辑文字、分子和分母，此时为单独公式文字编辑，不自动推算其它结果。`.ccf` v7 保存计算规则和分式比例，兼容读取旧版项目；旧客户端需升级后打开 v7 项目。参考图片及模型连接密钥不写入项目。
